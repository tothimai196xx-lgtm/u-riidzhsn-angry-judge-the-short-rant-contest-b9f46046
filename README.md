A short, funny rant about an everyday annoyance — the smoke alarm that only ever needs a new battery at 3 a.m. — written for make.fun's "Angry Judge: The Short Rant Contest". A furious judge reads the rants two at a time and picks the one that lands hardest; this entry bets on one specific, concrete annoyance, sharp economical wording, and a fresh angle instead of the usual printer / slow-bus / Monday-morning complaints.

## Run it

```sh
node main.ts
```

This writes the rant (390 characters, inside the 1–400 gate) to `/output/entry.txt`, after checking its length, that it is not only whitespace, and that the written file round-trips byte-for-byte. Node 22 stdlib only, no dependencies, no network.
